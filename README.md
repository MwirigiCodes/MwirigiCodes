## 📂 Featured Projects

### 🎯 [Notes API](https://github.com/MwirigiCodes/notes-api)

A **production-ready RESTful API** for managing personal notes with enterprise-level security and best practices.

**Key Features:**
- User authentication with JWT tokens and refresh token mechanisms
- Full CRUD operations for note management
- Role-based access control ensuring users can only access their own data
- Advanced security: bcrypt password hashing, HTTP-only cookies, rate limiting (100 req/15min)
- Input validation using express-validator
- Security headers with Helmet.js and CORS configuration
- Comprehensive error handling and status codes
- Docker containerization for easy deployment

**Tech Stack:** Node.js, Express.js 5.2, MongoDB 9.9, Mongoose, JWT, bcryptjs, Helmet, express-rate-limit

**Highlights:**
- Implements industry-standard authentication patterns
- Complete API documentation with usage examples
- Docker and Docker Compose support
- Follows RESTful conventions and HTTP standards
